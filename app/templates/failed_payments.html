{{ icon('info', 16) }} How this list is matched

Failed attempts come from the Buyers export because unsuccessful payments may never create a Registrant record. Only Payment Failed or Failed statuses are included; cancelled and pending payments are excluded.

A later registration with Payment Validated is matched by the same name and email or mobile number. When names are missing, both email and mobile must match. Dates use the original Created At values, not the time the files were imported. Only entries labeled No later paid registration appear below. Uncertain matches, incomplete identities, and existing paid registrations requiring review are excluded.

Only the active import for this event is compared. Repeat failed attempts with the same name and contact details are grouped; the latest failure is shown. Upload a fresh complete export to refresh the list.
